# Notion 项目工作台

创建五部分项目看板，并在每次实际推进后更新行动项、项目摘要和开发事件。Token 记录项目投入，不能代替进展、完成度或价值。

## 使用范围

沿用当前任务已明确授权的工作区、父页面与项目范围。用户要求维护已有工作台或调用本技能维护项目时，执行该范围内必要的页面、任务与事件更新，不重复请求已有授权。仅研究、分析或制作本地草稿的请求不授予云端写入；不要自行发布页面、通知他人、创建定时 Agent 或扩大到其他项目。

使用可用的 Notion 连接器，先发现它实际支持的读取、数据库、页面和视图能力。没有连接器或目标无法访问时，完成本地可审阅的更新草稿，报告未写入云端；不要把本地草稿当已同步。

## 先读取，再维护

1. 读取目标父页面、现有子页面和数据源，核对项目页面身份、属性类型、关联、视图与权限。已有本地绑定可用于定位，不能只凭同名选中任意库。
2. 复用 Projects、Tasks、Events、Usage Daily；重试也先查询现有记录。仅在当前授权范围内确实缺少资源时建立，保留已有页面和数据源身份。不要重跑初始化造出另一套库。
3. 普通项目更新只改有关任务、项目摘要和新增事件。新增列、关系或布局时阅读 [schema.md](references/schema.md)；建立或整理首页时阅读 [template.md](references/template.md)。旧字段可映射，不能为符合示例改坏现有计量结构。

## 固定给人看的五部分

按用户选择的顺序保留这五部分，不另换成复杂管理方法：

1. **愿景**：始终在首位，说明项目为谁解决什么问题、期望得到什么结果。已有愿景没有变化时保留原文。
2. **待人工确认**：只放具体选择、待验收成果或需人的行动；完成确认后从此视图移出，但保留对应 Tasks 和事件。
3. **当前进展与下一步**：实际完成了什么、仍缺什么，以及下一项可执行行动。单项目页面直接展示阶段、完成事实和 AI 下一行动，不重复同名 Project 卡；多项目入口可用项目卡。Tasks 视图隐藏已完成和取消，数据库里的已完成任务保留。
4. **历史开发事件**：默认以按日期排序的 Events 列表展示，提供可展开的原生时间线，关联项目和相关 Tasks，保留过程、结果和证据。
5. **每项目 Token 投入**：关联已计量摘要，展示时间范围和质量；用量不能被当作项目完成率。

使用 Notion 原生页面 icon、标题、分栏和数据库视图。任务卡片供人浏览，内部标识、摘要键和原始计量细分留在详细视图，不堆到首页。优先简洁可用，不为装饰加入无关图片或假指标。

## 每次实际推进都记事件

任务推进包括方案确定、实现、验证、发现阻塞、人工确认和交付等有实际结果的变化。更新当前状态之外，**必须追加 Events**：带时间、实际动作与结果、证据、Project 和相关 Tasks 关系。先查同次操作的 Event Key 或已存在事件，顺序重试复用已有记录。

同项目由一个写者顺序维护事件。Event Key 是富文本，没有唯一约束；先查后建不是原子操作，不保证并发唯一。创建后按键重新读取，核对只有一条。已有多条同键记录、并发结果或创建响应尚不确定时，标为待核实并暂停重复创建，保留现有历史，不自行删除、合并或改写事件。

- 事件是历史事实，Tasks 是当前状态。不能把一个 Tasks 行改名成下一项任务，删除已完成任务，或每次覆盖同一段“最新进展”冒充事件历史。
- 不覆盖、重排成新日期或删除以前的事实。需要更正时追加更正事件并指向原事件；状态倒退或任务重开也追加说明。
- 当前执行使用实际记录时间及用户时区。补录历史时，已知时间按证据填写；原完成时间未知时，记为“本次回填旧证据”的事件，Occurred At 用实际回填时刻，Result 明确“原完成时间未核实”。不能将回填时间宣称为过去完成时间，不编造截止日期。
- 证据可为获授权分享的 PR、提交、文档、验收页或结果摘要。仅本地的证据写成明确摘要或“本地验收，链接不可公开”，不上传原始日志、代码、对话、工具输出、绝对本机路径或会话／响应 ID。
- 没有实际推进就不制造“已完成”事件。能确认的结果和待验证部分分别写明。

## 当前状态的更新规则

项目 icon 必须有可显示的 emoji 或 Logo；创建项目时同步设置，已有项目缺失时补充或标为需设置。Notion 本身没有页面 icon 必填约束，不宣称已对所有入口强制校验。

下一步写具体动作和完成条件。状态、日期、验收及任务数量以已读取事实为准；未知数据保持未知，不用 Token、文本长度或模型猜测补成进度。确认完成的任务保留已完成状态，等待人工验收的成果留在待确认。

后台计量服务只读取管理缓存并同步 Token 摘要；本技能在当前任务中执行 AI 维护。未实际配置的定时 Custom Agent、自动复盘或通知不能宣称已运行，也不要仅因为使用本技能就创建这些服务。不要修改全局 AGENTS 或无关项目配置来启用本工作流。

## 投入与验收

计量只使用已有扫描器或经验证的摘要：Counted Tokens / Included、日期、来源、统计质量与截止时间。缓存与推理是细分项，不重复加总；日会话数不能相加当周会话数；不同设备或匿名来源未经去重不能强行合并。订阅额度百分比独立于本地 Token。

写入后重新读取有关页面、任务、事件和关系，确认五部分仍存在、已完成任务未删除、新事件可见且没有重复、用量筛选仍正确。网络超时或创建结果不确定时先重查，不盲目重复创建。报告实际写入结果、事件与任务链接、未核实项；只读或本地草稿要明确说明。
